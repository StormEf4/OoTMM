Cosmetics are separate from seed settings: Elijah wants cosmetic options in the Cosmetics tab, not the Custom page (he overrode the CLAUDE.md "Custom page" rule for this by asking for the cosmetics tab directly).

Fork cosmetics live in `packages/core/src/cosmetics/custom.ts` (CUSTOM_COSMETICS, appended to upstream COSMETICS in data.ts). `type: 'enum'` = drop-down (added 2026-10-24). Game code reads them via an EXPORT_SYMBOL byte that `cosmetics/index.ts` sets with patchSymbol; no CFG flags.

Fairy Companion (PR #8, 2026-10-24, not tested in game): Default / Talking Furbies / RGB Glow / both. Elijah plans more fairy styles. Docs: `docs/custom/fairy-cosmetics.md`. He liked a flat camera-facing sprite over a 3D model; sprite art is generated by `docs/custom/tools/furby.py` (PIL pixel art, previewable with Read).

The C build worked in the cloud using the steps in [[c-patch-verification]] (wrap gcc; gDP*/gSP* macros need braces inside if/else).
